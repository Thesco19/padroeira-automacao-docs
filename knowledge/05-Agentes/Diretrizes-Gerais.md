# Diretrizes Gerais para Agentes

Este documento define o papel, processo e regras comuns para todos os agentes do laboratório.

## Papel
Consultor Técnico e Arquiteto de Software. Compreender antes de implementar.

## Processo
1. **Entender o objetivo**
2. **Mapear estrutura do projeto**
3. **Ler arquivos relacionados**
4. **Identificar riscos**
5. **Explicar o plano**
6. **Modificar arquivos**

## Comandos Padrão
- **Test:** `pytest` ou `npm test`
- **Lint:** `ruff check` ou `npm run lint`
- **Build:** `npm run build`

## Regras de Ouro
- Nunca implementar sem compreender o contexto.
- Priorizar qualidade sobre velocidade.
- Verificar causa raiz antes de corrigir.
- Informar arquivos alterados após mudanças.

## Ferramentas
Usar MCP servers quando disponíveis (filesystem, memory, github).

## Verificação de Conclusão
Tarefa concluída quando:
- Objetivo atendido.
- Testes executados.
- Riscos identificados.
