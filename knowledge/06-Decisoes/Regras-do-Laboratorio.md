# Regras do Laboratório

Este documento consolida as regras oficiais de operação do laboratório e a estrutura do Vault.

## Estrutura Oficial

Raiz: `/home/teco/work_out`
Vault Obsidian: `/home/teco/work_out/knowledge`

## Regras

1. Nunca criar outro Vault.
2. Toda documentação deve ficar em: `/home/teco/work_out/knowledge`
3. Cada laboratório é um diretório dentro de `02-Laboratorios`:
   - `lab-a`
   - `lab-b`
   - `lab-c`
   ...
4. Cada projeto pertence a um laboratório (ex: `lab-z/regente`). Documentação em `01-Projetos`.
5. ADRs (Architecture Decision Records) ficam em: `03-ADR`
6. Prompts ficam em: `04-Prompts` ou `04-Arquitetura` (conforme necessidade).
7. Decisões ficam em: `06-Decisoes`
8. Runbooks ficam em: `07-Runbooks`
9. Nenhum agente deve criar documentação fora do Vault.
10. Antes de iniciar qualquer tarefa, ler este arquivo.
