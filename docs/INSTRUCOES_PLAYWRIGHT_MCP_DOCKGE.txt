# Instruções Simplificadas: Playwright MCP no Dockge

## 1. Arquivos Necessários

### `seccomp_profile.json`
```json
{
  "defaultAction": "SCMP_ACT_ERRNO",
  "architectures": ["SCMP_ARCH_X86_64", "SCMP_ARCH_X86", "SCMP_ARCH_X32"],
  "syscalls": [
    {
      "names": ["clone", "setns", "unshare"],
      "action": "SCMP_ACT_ALLOW"
    }
  ]
}
```

---

### `docker-compose.yml`
```yaml
services:
  playwright-mcp:
    image: mcr.microsoft.com/playwright:v1.61.0-noble
    container_name: playwright-mcp
    ports:
      - "3000:3000"
    user: pwuser
    init: true
    ipc: host
    security_opt:
      - seccomp:/seccomp_profile.json
    volumes:
      - ./seccomp_profile.json:/seccomp_profile.json
    command: >
      /bin/sh -c "npx -y playwright@1.61.0 run-server --port 3000 --host 0.0.0.0"
    restart: unless-stopped
```

---

## 2. Comando para Subir a Stack

## 3.1. Corrigir o `docker-compose.yml` (Solução Definitiva)
**Problema:** O Docker não encontra o arquivo `seccomp_profile.json` porque o caminho relativo não está sendo resolvido corretamente dentro do container.

**Solução:** Use o **caminho absoluto** do host no `docker-compose.yml`.

### Comando para Corrigir
Execute no terminal:
```bash
cd /opt/stacks/playwright-mcp && \
sed -i 's|      - .*/seccomp_profile.json:/seccomp_profile.json:ro|      - /opt/stacks/playwright-mcp/seccomp_profile.json:/seccomp_profile.json:ro|' docker-compose.yml
```

### Conteúdo Corrigido do `docker-compose.yml`
```yaml
services:
  playwright-mcp:
    image: mcr.microsoft.com/playwright:v1.61.0-noble
    container_name: playwright-mcp
    ports:
      - "3000:3000"
    user: pwuser
    init: true
    ipc: host
    security_opt:
      - seccomp:/seccomp_profile.json
    volumes:
      - /opt/stacks/playwright-mcp/seccomp_profile.json:/seccomp_profile.json:ro  # <-- Caminho absoluto
    command: >
      /bin/sh -c "npx -y playwright@1.61.0 run-server --port 3000 --host 0.0.0.0"
    restart: unless-stopped
```

### Explicação
- **`/opt/stacks/playwright-mcp/seccomp_profile.json`**: Caminho absoluto no host.
- **`:ro`**: Montagem somente leitura (recomendado para segurança).
- **Resultado**: O Docker encontrará o arquivo e o servidor MCP subirá sem erros.

---

## 3.2. Subir a Stack
Após corrigir o `docker-compose.yml`, execute:
```bash
cd /opt/stacks/playwright-mcp && docker compose down && docker compose up -d
```
