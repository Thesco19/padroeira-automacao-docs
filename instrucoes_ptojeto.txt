# ESPECIFICAÇÃO TÉCNICA: SINCRO DE PLANILHAS PARA DISPARO DE CARDÁPIO (AIDER)

## 1. ESCOPO DO SCRIPT
Construir um módulo em Python que valide, higienize e estruture a lista de contatos extraída do Windows para o formato consumido pelo n8n.

## 2. REQUISITOS DO ARQUIVO DE ENTRADA (PLANILHA/CSV)
O arquivo gerado no Windows e enviado ao Linux deve seguir rigorosamente o padrão:
- Colunas necessárias: `Nome`, `Telefone`, `Lista` (Identificador de qual das 3 listas o cliente pertence).
- O script em Python deve higienizar os números de telefone:
  - Garantir o DDI Internacional (`55` para Brasil).
  - Remover espaços, parênteses e hifens.
  - Validar se o número possui a quantidade correta de dígitos (adicionar ou tratar o nono dígito se necessário para o padrão do WhatsApp).

## 3. ARQUITETURA DE INTEGRAÇÃO COM N8N
O fluxo final do n8n funcionará assim:
1. Recebe o gatilho (Trigger) do Telegram com a foto do cardápio do dia.
2. Lê a planilha de contatos higienizada (`contatos.csv`).
3. Filtra os números válidos.
4. Repassa os dados linha por linha no loop do `Split In Batches` para a Evolution API com delay randômico humano (3000ms a 8000ms).

## 4. REQUISITOS DE CÓDIGO
- Linguagem: Python (compatível com alias 'python' apontando para python3).
- Adicionar type hints estritos em todas as funções.
