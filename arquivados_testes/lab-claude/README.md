# Lab Claude

Servidor HTTP simples usando apenas a biblioteca nativa do Node.js.

## Pré-requisitos

- [Node.js](https://nodejs.org/) versão 18 ou superior.

## Como rodar

```bash
# Inicia o servidor na porta 3000 (padrão)
npm start

# Ou define uma porta customizada
PORT=8080 npm start
```

Acesse `http://localhost:3000` no navegador.
